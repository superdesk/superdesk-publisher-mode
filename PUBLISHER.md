# Superdesk Publisher Mode tweaks
This is the work in progress repo for preparing the desired setup for the Superdesk Publisher Mode. Eventually, this repo will cease to exist as the Publisher Mode is instututionalized in the main Superdesk repos.

## Publisher Mode specifics
- Corrections workflow `on`
- Correction -> Update
- User roles without Update, Kill, Takedown
- Keywords setup `on` by default 
- Publisher friendly default data
